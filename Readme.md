# Bike Sharing Dataset Analysis

This project is a data analysis of a bike sharing dataset, focusing on uncovering insights about how weather, temperature, holidays, and other factors influence bike rental behavior during weekdays and weekends.

## 📌 Project Objectives

- Understand how weather and holidays affect bike rentals.
- Identify trends in bike usage across different months and conditions.
- Use data visualization and statistical analysis to support insights.

## 🔍 Business Questions

1. How do temperature and weather conditions (e.g., rain and holidays) affect the number of bike rentals on weekdays compared to weekends?
2. Which month has the highest number of bike rentals, and how does the weather during that month influence user behavior?

## 📁 Dataset

The dataset used in this project is sourced from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/Bike+Sharing+Dataset). It contains daily and hourly data on bike rentals, weather, temperature, and more.
